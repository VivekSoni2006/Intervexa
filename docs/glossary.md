# Glossary

- **Access token**: Short-lived Supabase Auth credential sent by the browser to protected API routes.
- **API**: The Express endpoints under `/api/v1`.
- **Gemini**: AI provider used for question generation and assessment.
- **Deepgram**: Speech provider used for audio transcription and the backend voice-agent gateway.
- **Publishable key**: Supabase client key intended for browser use; it is not an admin credential.
- **RLS (Row-Level Security)**: PostgreSQL policies that restrict rows to authorised users.
- **Session**: One interview or written-exam attempt.
- **Supabase Storage**: Object storage used for supported uploaded assets.
- **WebSocket**: Persistent bidirectional connection used by the backend live voice gateway.
